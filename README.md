# orar_facultate
Acest orar, este creat special pentru studentii de Mecatronica 3.1, in anul universitar 2026-2027. 
Proiectul este realizat de catre **AlexMAIM**, cu ajutorul Inteligentei Artificiale. 

Notițele adăugate pe activitățile din orar se salvează local în browser, în format JSON (`localStorage`, cheia `uniScheduleNotes`). Ele rămân disponibile pe același browser și dispozitiv și nu se sincronizează între dispozitive.
